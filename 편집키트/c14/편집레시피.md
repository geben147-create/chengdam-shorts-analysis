# 편집 레시피 — 청담언니 14위 「뭘해도 안되는날 다들 있으시죠😆 🫣」

원본: https://www.youtube.com/watch?v=VCClwwc95jo

## 촬영 샷 리스트
- 정면 삼각대(가슴 높이, 1m) 얼굴 + 작업대 미디엄샷 — 모든 요리 촬영 때 리액션 확보용으로 항상 돌려두기
- 실패 순간 뒤 3초간 표정 유지(바로 멈추지 말 것)
- 창가 45° 하이앵글 팬 전체샷(뒤집기·붓기용)
- 수직 탑다운(도마 위 60~70cm, 재료 6개 2×3 격자) — X/O 비교용
- 같은 앵글로 재도전 성공 컷
- 체념하고 먹기 같은 여운 행동 2초

## 편집 순서
1. 타임라인 0초에 가장 큰 사고 원테이크(3~4초)를 통째로 놓고, 사고 0.5초 전부터 시작하도록 앞을 자른다
2. 다른 날 NG 4~5개를 1.2~3초씩 하드컷으로 이어 붙인다(자막 없음, 전환 효과 없음)
3. 요리 실패 1개 뒤에 원인 자막: 흰 굵은 고딕 + 빨강 네온 글로우(CapCut 텍스트 > 스타일 > 글로우), 애니메이션 '타자기', 마지막에 X
4. X가 완성되는 프레임에 버저 효과음(BGM보다 +3dB)
5. 해결 동작은 탑다운 소스에서 0.2~1.3초 점프컷 3~11개로 압축하고, 초록 글로우 해결 자막(O 기호)으로 교체 — 손 작업이 위쪽이면 자막을 하단으로
6. 성공 컷에 1초 동안 100→112% 키프레임 확대(푸시인) + 상승 차임
7. 중간에 얼굴 NG 2~3개를 다시 넣어 웃음 재점화 — 체념 리액션 컷에서는 BGM을 1~2초 빼고 단음 효과만 남김
8. 경쾌한 저작권 무료 BGM 1곡을 깔고(체념 리액션 컷만 예외로 뺌), 사고 순간 감탄음·현장음은 살린다
9. 마스터 -9~-8 LUFS, 리미터 -1dBFS(원본처럼 클리핑은 피함)
10. 마지막 O 자막 뒤 손 제스처 0.5초에서 끊거나, 첫 컷으로 이어지는 루프 컷 추가

## 컷 리듬 기준
- 평균 1.79초 · 분당 33.5컷 · 빠른 구간: 19.03~19.57s 컷 11(0.30s)·12(0.23s) 점프컷 2연타(반죽 덧바르기 탑다운) / 34.60~35.43s 컷 20(0.37s)·21(0.47s) / 40.25~41.00s 컷 25(0.30s)·26(0.45s) — 모두 같은 앵글 안 '죽은 시간' 삭제용
- 배속: 뚜렷한 배속·슬로모 없음(전 컷 1x 추정). 컷 15 끝의 확대는 편집 줌(디지털 푸시인) 추정

## 소리
- BGM을 크게 깔고(컷 17만 제거) 판정 효과음(버저·차임)을 BGM보다 더 크게 올려 '틀림/맞음'을 귀로 판정. 지글·톡톡 현장음은 BGM 아래로 묻힘. 전체를 -8 LUFS 가까이 끌어올린 공격적 마스터(피크 +1.3dBFS)

## 자막 규격
| name | spec | use |
|---|---|---|
| 오답 X 자막 | 흰 굵은 둥근 고딕 + 빨강 네온 글로우 외곽선, 2줄 + 흰 X 기호, 타자기 등장, 글자 높이 약 6.6~7% | 실패 원인(컷 8~9, 22~24, 29~30) |
| 정답(해결) 자막 | 흰 굵은 둥근 고딕 + 초록 네온 글로우 외곽선, 2줄, 글자별 팝 등장. 세트 2·3만 O 기호(세트 1은 기호 없음). 세트 1·3은 X와 같은 자리, 세트 2는 상단 X → 하단 O로 이동 | 해결법(컷 10~15, 24~28, 30~32) |
| 보조 라벨 | 작은 흰 글씨 + 초록 외곽선 한 단어 | 도구 이름 표시(39.5s 부근 '칼집') |
