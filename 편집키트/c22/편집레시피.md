## 촬영 샷 리스트
- 정면 삼각대(가슴 높이, 인물 1.2m): 생 파인애플을 렌즈 30cm까지 내밀고 도마에 쿵 → 칼질 → 슬라이스 까꿍
- 탑다운 암(도마 60~70cm 위): 슬라이스 2x3 배열 → 커터 찍기 → 심 빼기(각 동작 1초씩) → 완성 격자 3초 정지
- 도마 높이 아이레벨(얼굴 프레임 밖): 적양파 두껍게 썰기 → 칼로 떠서 노란 접시로
- 정면: 양파 링 뽑아 링 너머 얼굴 까꿍 / 양파 링을 파인애플 링에 끼워 렌즈로 내밀기
- 탑다운(노란 접시·회색 상판): 양파 링 배치 → 가득 찬 접시 정지 컷
- 탑다운: 파인애플 링 6개에 양파 링 끼우기 → 완성 격자 정지
- 정면: 대패삼겹을 트레이에서 길게 들어 렌즈를 덮기(가림 전환 소스)
- 탑다운(위쪽 고기 트레이): 링에 고기 감기, 구멍으로 손가락 내밀기 2회, 도넛 하나 완성마다 1초씩
- 창가 45도: 후추 그라인더·양념병 흔들기(마이크 병 옆 40cm) → 푸시인
- 정면 와이드: 밀가루 붓기·계란 깨기·빵가루 붓기를 같은 자리에서
- 탑다운 세로 3색 접시: 밀가루→계란→빵가루, 도넛을 렌즈로 들어 올리기 2회
- 테이블 높이: 튀김옷 입힌 도넛 5개 전경 + 몸통 배경
- 창가 45도·팬 높이 아이레벨: 기름 투입 기포 → 튀김 근접 → 집게로 건져 렌즈로
- 탑다운 망 트레이: 튀긴 도넛 2x3 정렬 → 완성 정지 컷
- 정면: 튀긴 도넛 까꿍 → 몸통 정면 6층 쌓기(한 층마다 1초) / 창가 아이레벨: 소스·마요 드리즐
- 정면+옷깃 마이크: 도넛 흔들기(썸네일) → 한입 크런치 3초 → 단면을 렌즈 15cm 앞 → 엄지척(첫 컷과 같은 구도)

## 편집 순서
1. 1) 타임라인 순서: 훅(얼굴+파인애플) → 파인애플 링 → 양파 링 → 결합 → 고기 감기 → 시즈닝 → 튀김옷 → 튀기기 → 6층 쌓기·아이싱 → 먹방·단면. 목표 59초
2. 2) 훅 0~4.9초는 컷 2개로: 첫 컷 0.8초(내밀기·쿵), 둘째 컷 4초(칼질+까꿍). 첫 프레임에 얼굴과 재료가 모두 보이게
3. 3) 탑다운 반복 구간은 같은 구도 소스를 0.2~0.5초씩 잘라 결과 상태만 이어 붙임(점프컷 60개 목표), 반복 방법의 첫 회만 0.9~1.1초
4. 4) 단계 끝마다 완성 격자 0.5초 정지 → 마지막 0.2~0.3초 스케일 100→170% 키프레임 + 방향 블러(크래시 줌) 5회
5. 5) 새 재료는 정면 얼굴 컷으로 시작(링 까꿍·렌즈 가림), 얼굴 컷은 1.2~2.3초로 길게 둬 쉼표 역할
6. 6) 창가 세트 컷을 약 28·38·47초에 끼워 장소 전환 리훅
7. 7) 45초 이후는 컷 길이를 1~3초로 늘려 감속: 6층 쌓기(컷 안 점프 4회) → 소스 롱테이크 1.9초 → 크런치 3.3초
8. 8) 오디오: 밝은 멜로디 BGM을 전체에 깔고, 칼질·과즙·양념병·빵가루·쌓기·크런치 구간만 현장음 +3~8dB, 크런치 순간 BGM -3~6dB 덕킹. 마스터 -13 LUFS 전후 + 리미터 -1dBFS
9. 9) 자막 없이 내보내고, 마지막 엄지척 컷을 첫 프레임과 같은 구도로 맞춰 루프 확인. 썸네일은 도넛을 든 얼굴+탑 장면(#86)으로 따로 지정

## 컷 리듬 기준
- 평균 0.67초 · 분당 89.8컷 · 빠른 구간: #59~#67(34.62~37.88초) 9컷 3.26초, 평균 0.36초(초당 2.8컷) — 튀김옷 반복. 순간 최고는 #34~#38(21.87~23.22초) 5컷 1.35초(초당 3.7컷), 최단 컷 #34 0.10초·#59 0.17초·#8·#19 0.18초.
- 배속: 뚜렷한 스피드 램프 없음. #8·#19·#31·#59만 1.5~2배속 추정(손 블러·짧은 길이). 압축은 배속보다 같은 구도 점프컷(63개)과 컷 안 점프(약 9회)로 한다.

## 소리
- BGM을 바닥에 깔고 재료 소리를 구간별로 3~10dB 올리는 2층 믹스. 마스터 -12.9 LUFS로 크게 압축, LRA 8.9LU로 조용한 과정(-25~-34dB) ↔ 크런치·빵가루(-15~-17dB) 차이를 둔다. 트루피크 +1.0dBFS는 리미터로 -1dBFS 이하로 낮출 여지.
