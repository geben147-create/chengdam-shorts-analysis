9. 24번: 3.9초 긴 컷 안에서 자막은 그대로 두고 동작만 점프(41.3·42.5s) — 자막 가독성과 속도를 동시에.
10. 27~32번: 김 오각형 하나 붙일 때마다 컷(0.15~0.42초), 효과음 없이 음악만 — 빡빡빡 리듬.
11. 33번: 두 번째 반구 장식 과정은 통째로 생략 점프 — 반복 작업은 한 번만 보여준다.
12. 35번: 반구 속에 글자 젤리를 채워 '합치면 뭐가 될까' 마지막 깜짝 요소.
13. 38번: 완성품은 얼굴 앞에 들고 눈 크게 + 엄지척 — 얼굴은 판정 순간에만 등장.
14. 2·3번→40~42번: 도입의 젤리 반구 실패를 마지막 4초 보너스(젤리 축구공 음료)로 회수.
15. 41번: 탄산 붓는 소리(고역비 0.164, 영상 최고)로 피날레를 청량하게 닫는다.

### 편집 순서
1. 0~6s: 실패 원테이크를 자르지 않고 통째로 배치, 자막 없이 비명 구간 볼륨 유지
2. 6~9s: 두 번째 실패(다른 재료) 2컷 + 시무룩 얼굴 1컷
3. 실패 컷마다 X 자막(흰 글자 + 빨강 글로우, 글자별 팝인 0.05초 간격) — 첫 X에만 'sad trombone' 효과음
4. 해결 컷마다 O 자막(초록 글로우) + 같은 'correct chime'을 매번 반복
5. 같은 구도 반복 작업은 0.3~0.8초 점프컷, 자막은 여러 컷에 걸쳐 유지
6. 장소 전환은 피사체로 렌즈를 덮는 매치컷 또는 빈 화면 0.5초
7. 성공 리빌은 실패와 같은 구도 컷 + 차임 + 환호 표정
8. 조립 몽타주: 부품 하나에 한 컷(0.15~0.4초), 효과음 빼고 음악만
9. 피날레 4초 무자막 히어로샷 + 탄산·지글 현장음 키우기
10. 마스터: 약 -10 LUFS, 트루피크 -1 dBTP 리미터(원본은 +0.9 dBFS로 초과)

## 🐹 적용하기
- **그대로 가져갈 것**: 0~3초 원테이크 실패 + 비명 + 정적(자막 없이) / X/O 네온 판정 자막 + 실패음·정답 차임 짝 / 실패와 성공을 같은 구도로 찍는 콜백 / 조립 단계 0.15~0.4초 점프컷 몽타주 / 나레이션 없이 표정·자막·효과음만으로 다국어 이해 / 시즌 이벤트(월드컵 등) 모양 음식 + 보너스 결과물
- **바꿀 것**: 트루피크 +0.9 dBFS 클리핑 → 마스터에 -1 dBTP 리미터 / 첫 프레임에 목표 힌트(작은 축구공 소품·완성 사진 PIP 0.5초)를 넣어 무음 자동재생에서도 목표 전달 / 현장 바삭음이 약함(고역비 평균 0.061) — 1번 5.1s·34번 크런치를 3~6dB 키우기 / X 자막 위치가 상단·중상단·하단으로 흩어짐 → 한 위치로 통일하면 더 빨리 읽힘
- **AI 동물 캐릭터 쇼츠에 옮기면**: AI 캐릭터(예: 앞치마 두른 작은 햄스터 셰프)가 시즌 모양 음식(축구공 주먹밥·트리 모양 라면땅)을 뒤집다 0~2초에 와르르 무너뜨리고 비명 → X/O 판정 자막으로 시행착오 3번 → 같은 구도에서 성공 → 0.2초 조립 몽타주 → 창가 히어로샷. 판정마다 같은 차임을 반복하고 마지막에 첫 실패 재료로 보너스 컷.
- **실사 채널에 옮기면**: 정면 스튜디오(리액션)·탑다운 조리대(조립)·45° 창가(조리) 3세트를 고정 설치. 실패 테이크를 먼저 찍어 원인별 X 자막, 해결 테이크에 O 자막. 성공 컷은 실패 컷과 같은 위치에서 다시 찍고, 반구 2개 합체 + 속 재료 깜짝 공개 후 같은 테마 음료로 보너스 마무리.
