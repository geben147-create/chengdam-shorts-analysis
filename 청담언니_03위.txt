## 🐹 적용하기
- **그대로 가져갈 것**: 빈 캐릭터 틀로 시작해 '무엇을 만들까' 질문을 0초에 던지기 / 탑다운 구도 유지 + 동작 하나=컷 하나 점프컷 / 리빌 2~3회 구조(1차 결과 → 시즌 상징물 → 합체 클라이맥스) / 냉동·굳히기 대기를 1초 안팎의 전환 장치로 삭제 / 완성 장면만 뷰 좋은 장소로 옮기기 / 자막 없이도 이해되는 순서 설계 + 원색 보색 팔레트
- **바꿀 것**: 첫 프레임에 완성물 실루엣을 0.3초 플래시로 먼저 보여 주면 훅 점수 상승 여지(현재는 빈 틀만) / 온셋 일치율이 우연보다 낮음 — 칼질·붓기 타격점에 컷을 맞추면 ASMR 쾌감을 더 키울 수 있음 / True Peak +1.9dBFS는 클리핑 위험 → -1dBTP 리미터 권장 / 기념일 의존형이라 비시즌에는 상징물만 교체(생일 케이크 토퍼·크리스마스 트리 등) / 가전 로고가 노출되는 컷(27)은 협찬이 아니면 로고를 가리는 구도로
- **AI 동물 캐릭터 쇼츠에 옮기면**: AI 캐릭터(예: 동물 캐릭터)가 자기 모양 얼음틀에 과일을 채워 얼리고, 그 나라 기념일 상징(깃발·등불 등) 초콜릿을 꽂아 음료에 띄우는 60초 비언어 쇼츠. 탑다운 고정 채우기 20컷 → 냉동 1초 → 언몰딩 리빌 → 붓기 클라이맥스 → 캐릭터 먹방·엄지척 루프.
- **실사 채널에 옮기면**: 시즌 캐릭터 틀 과일 얼음 시리즈: 추석(달토끼+송편 초콜릿)·크리스마스(곰+트리 초콜릿)·어린이날(공룡+풍선 초콜릿). 같은 탑다운 삼각대 위치·같은 볼·같은 붓기 엔딩으로 템플릿화.
