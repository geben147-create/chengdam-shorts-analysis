### 소재
- **소재**: 본편: 50cm 안팎의 긴 소세지 1줄(세로로 갈라 테두리로 사용) + 채소 다진 감자샐러드 속 + 치즈, 밀가루(접착), 전기팬·창가 철판. 콜드오픈 NG: 초록 대야의 빨간 젤리 시트, 채칼(슬라이서)과 통무.
- **새로움·비틀기**: 빵 반죽 대신 긴 소세지 한 줄로 튀르키예식 '피데(보트 모양 빵)' 테두리를 만든다는 발상 + 그 과정의 실패(테두리가 오징어처럼 말려 분리)를 숨기지 않고 해결 팁 콘텐츠로 바꿨다. 해외 댓글에서 피데·이라크 빵과 닮았다는 반응이 나옴.
- **시즌·트렌드 연결**: '실패→해결(fail to fix)' 구조는 요리 팁 쇼츠의 대표 포맷이고, 실패 장면 자체가 글로벌 공감 코미디라 언어 없이 통한다. 채널 인기 NG(댓글이 기억하는 채칼 무 장면)를 다시 넣어 팬의 기억을 소환한다.
- **채널 반복 요소**: 청담언니의 NG·비하인드 계열(섹터 ng) — 같은 스튜디오(반짝이 가랜드·흰 벽)와 보라 니트릴 장갑이 모든 컷에 이어지고, 과거 영상 NG 클립을 콜드오픈으로 재활용하는 구성(추정).

## 떡상 공식
0.0~2.4초: 채널 과거 NG 중 가장 그림이 센 것(거대 빨간 젤리 시트)을 첫 프레임에 두고, 2.4초에 찢어지는 실패로 바로 보상 → 2.4~3.6초: 멋쩍은 표정 + 고음 지속 효과음으로 첫 웃음 마무리 → 3.6~5.8초: 옷이 바뀐 두 번째 NG(채칼 무가 렌즈로 날아옴) → 비명 얼굴 편집 펀치인 줌 → 5.8~8.3초: 이번 편 주인공 소재(긴 소세지)를 얼굴 옆에 들고 휘어지는 코믹 리액션으로 소개 → 8.3~15.0초: 제목 속 실패 실연 — 테두리 소세지가 속재료와 분리돼 오징어처럼 말림, 되감기 2회로 반복 → 15.0~19.7초: 탑다운으로 전환해 원인 공개 — 빨강 글로우 X 자막 + 오답 버저 2연타 → 19.7~26.5초: 해결 1 — 앞뒤 번갈아 비스듬히 칼집 점프컷(크롭 확대/원래 교차), 초록 O 자막 + 정답 차임 → 26.5~30.8초: 세로로 가른 소세지를 다이아몬드(배) 모양으로 벌리고 안쪽에 밀가루 → O → 30.8~37.5초: 숟가락으로 누르기 X → 손으로 둘러 밀착 O, 오답-정답 한 쌍 대비 → 37.5~41.3초: 창가 철판 45° 핸드헬드, 뒤집기 9컷 몽타주(평균 0.42초) + 지글 ASMR 폭발 → 41.4~43.1초: 스튜디오 정면으로 복귀, 완성 보트를 집게로 세워 얼굴 옆에서 웃고 42.5초 윙크 + 반짝 차임 → 첫 장면(같은 스튜디오 정면)으로 루프

## 🔊 소리·ASMR

말소리 0초(Whisper 0문장) — 낮게 깔린 귀여운 BGM + 구간별로 켰다 끄는 현장음 + 코믹·퀴즈 효과음 약 10개로만 이야기한다. 통합 -10.7 LUFS(매우 큼), LRA 15.1LU(조용함-큼 편차가 큼), 트루피크 +1.2dBFS(클리핑 위험), 무음 1.8%. 온셋 94개·초당 2.18개, 고역비 평균 0.18. 컷-온셋 일치 39.4% vs 우연 34.9%로 전체는 '동작·자막 타이밍 편집'이지만, NG 콜드오픈과 철판 몽타주 경계만 타격음에 붙여 잘랐다.

- **ASMR(현장음)**: 구간별 on/off: 실패 구간 #5 지글(고역비 0.46, 중심 4.5kHz)·#8(0.25) 켬 → 해결 강의 #9~24 거의 끔(고역비 0.00~0.18, rms -27~-43dB, 칼질·밀가루 소리 안 들림) → 철판 #25~33 다시 크게(고역비 0.33~0.51, 중심 4.3~5.1kHz, 초당 온셋 6~8).

- **목소리 상세**: 없음 · 없음(비명 추정 현장음만) · 해당 없음 — Whisper 0문장, 비명 표정 4.3~5.8초 구간만 목소리 추정

### 다른 쇼츠와 확실히 다른 점
1. 요리 쇼츠가 보통 완성품으로 여는 것과 반대로, 다른 날 다른 옷의 NG 2개를 5.8초 안에 연타해 '실패 모음'으로 연다 — 본편 소재(소세지)는 그다음.
2. 정보 자막을 O/X 퀴즈 카드로 바꾸고 버저·차임을 짝지어, 대사 0초로도 '틀린 방법 vs 맞는 방법'이 게임처럼 전달된다(빨강/초록 색만으로도 판정 인지).

## 🔤 자막

자막 카드 5개(X 2개·O 3개)만 쓰고, 첫 17.5초 NG 구간은 자막 0. 모든 자막은 화면 상단 중앙에 같은 형식으로 뜨고, 판정 기호(O/X)와 효과음이 함께 붙는 '퀴즈 카드' 역할.

- **빈도**: 5개/43.1초, 화면 노출 합계 약 7.4초(약 17%). 0~17.5초 0개, 17.5~37.5초 20초 동안 5개(약 4초에 1개)
- **근거**: 문장이 짧고(각 2줄) 색·기호로 판정을 알려 번역 없이도 이해 가능. 원문 자막은 '어떻게 하면 X / 이렇게 하면 O' 의도만 담고 수량·시간 같은 숫자 정보는 없다. 해외 시청자(댓글 약 38%)도 O/X 기호와 차임·버저로 정답을 알 수 있다.

| 스타일 | 규격 | 용도 |
|---|---|---|
| X 오답 카드 | 흰 볼드 고딕 2줄 + 두꺼운 빨강 외곽선·빨강 글로우, 아래 큰 흰 X(빨강 테두리). 상단 중앙 y 0.10~0.17, 글자 높이 화면의 약 5.6~6.2%. 타자기식 등장 + 오답 버저 | #8(약 17.5~19.7초) 칼집 없는 통소세지, #20~21(약 32.0~33.6초) 숟가락 누르기 |
| O 정답 카드 | 같은 형식 + 초록 외곽선·초록 글로우, 아래 큰 흰 O(초록 테두리). 글자 높이 약 6.9~7.5%. 타자기식 등장 + 정답 차임 | #14~15(약 24.9~26.55초) 앞뒤 번갈아 칼집, #19(약 29.8~30.7초) 밀가루, #23~24(약 36.5~37.5초) 손으로 둘러 밀착 |

### 촬영 샷 리스트
- 스튜디오 정면 삼각대(가슴 높이, 인물 1.2m): 요리할 때 늘 녹화를 켜 두고 NG가 나도 끊지 않기 — 콜드오픈 소스
- 정면: 채칼·젤리처럼 '튀거나 찢어지는' 소재는 렌즈 앞 30cm에 투명 아크릴 보호판, 60fps
- 정면: 주인공 소재(긴 소세지)를 얼굴 옆·머리 위로 들고 과장 리액션 2~3초
- 정면: 전기그릴 위 실패 과정 롱테이크(집게로 들어 올리기 2회), 그릴 옆 30cm 샷건 마이크로 지글 수음
- 탑다운(전기팬 위 60cm): 실패 전 상태 3초 + 집게로 들어 테두리만 말리는 순간
- 탑다운 암(월넛 도마 + 흰 유산지, 50cm 위): 칼집 → 굴려 뒤집기 → 반대 칼집 → 휘어서 칼집 보여주기
- 탑다운: 세로로 가르기 → 양끝 잡고 다이아몬드로 벌리기 → 안쪽 밀가루 → 숟가락으로 누르기(오답용) → 손으로 둘러 누르기(정답용) + OK 손짓
- 창가 45° 핸드헬드(자연광): 철판 위 4~5개 동시 조리, 뒤집을 때 렌즈 쪽으로 넘기기 — 1.5~2배속용으로 길게
- 스튜디오 정면: 파란 접시 위 완성품을 집게로 세워 얼굴 옆에 대고 웃음·윙크(첫 컷과 같은 구도)

### 편집 순서
1. 1) 콜드오픈: 가장 그림이 센 과거 NG를 0~3.6초에 두고 실패 순간이 2.5초 안에 오도록 앞을 자른 뒤, 찢어지는 프레임에 코믹 효과음(휘슬·우는 소리)
2. 2) 두 번째 NG 1.2초 + 비명 얼굴 컷에 스케일 130%→100% 키프레임(0.8초 이징)으로 펀치인
3. 3) 주인공 소재 소개 2.5초 → 실패 롱테이크 6~7초, 실패 정점 뒤 0.3초 구간을 복제해 역재생·2배속으로 되감기 삽입(2회), 두 번째 되감기 끝에서 탑다운으로 하드컷
4. 4) 원인 컷: 흰 볼드 2줄 + 빨강 외곽선·글로우 자막을 타자기 애니메이션(약 0.5초)으로, 아래 X 기호 + 오답 버저 2연타
5. 5) 해결 과정: 같은 탑다운 소스를 0.5~1.3초 점프컷, 컷마다 스케일 100%/120% 번갈아(크롭 교차) — 칼질 현장음은 음소거하고 BGM만
6. 6) 팁마다 초록 외곽선 O 카드 + 정답 차임, 오답(숟가락) X 바로 뒤에 정답(손) O를 붙여 대비
7. 7) 과정 사이 결과만 보여줄 곳에 0.15초 초단컷(예: 가른 뒤 모습) 삽입
8. 8) 조리 몽타주: 뒤집기 소스를 1.5~2배속 후 0.15~0.6초로 9컷 3.8초, 뒤집는 모션 블러 프레임을 컷 경계로, 지글 현장음 +6dB
9. 9) 결말: 정면 스튜디오 완성품 컷으로 하드컷, 윙크 프레임에 반짝 차임, 첫 프레임과 같은 스튜디오 구도로 루프 확인
10. 10) 마스터: BGM -30dB 안팎, 효과음·현장음 우선, 통합 -11~-12 LUFS, 트루피크 -1dBFS 리미터

## 🐹 적용하기
- **그대로 가져갈 것**: 완성품이 아니라 '실패 한 번'으로 여는 콜드오픈, 실패 정점은 2.5초 안 / 과거 NG 2개를 3.6초 간격으로 연타하고 옷·장소로 '다른 날'임을 보여주기 / 문제→원인 X→해결 O→결과 순서, O/X 카드와 버저·차임을 반드시 짝으로 / 되감기(역재생)로 실패를 한 번 더 보여주고 그대로 원인 분석 컷으로 넘기기 / 해결 강의는 조용히, 마지막 조리 장면에서 지글 ASMR과 초단컷 몽타주로 가속 / 얼굴은 실패 리액션과 성공 미소에만, 정보는 탑다운 손으로
- **바꿀 것**: 첫 3초가 1컷이라 느리다 — 젤리가 들리는 0.0~0.8초를 줄이고 찢어지는 순간을 1.5초 안으로 당기기 / 제목 소재(소세지)가 5.8초에 나오므로, 첫 프레임 한쪽에 완성 소세지 보트를 작게 보여주거나 콜드오픈 NG를 1개로 줄여 약속 회수를 앞당기기 / 트루피크 +1.2dBFS·-10.7 LUFS는 과함 — -1dBFS 리미터, -12 LUFS 전후로 / O/X 카드에 숫자 정보(칼집 간격·밀가루 양)를 한 줄 추가하면 저장·공유 가치가 올라감 / 결말에 한 입 먹는 소리(바삭·치즈)를 0.5초 넣으면 NG→성공의 보상이 더 선명해짐
- **AI 동물 캐릭터 쇼츠에 옮기면**: AI 캐릭터 셰프(예: 작은 동물 캐릭터)가 과거 실패 2개(젤리가 찢어져 떨어짐, 채칼 채소가 렌즈로 날아옴)를 3.5초씩 보여준 뒤, 이번 요리가 말려 분리되는 실패를 되감기 효과로 두 번 → 탑다운 X 카드+버저 → O 카드 3개+차임으로 해결 → 철판 뒤집기 9컷 → 완성품 들고 윙크. 대사 없이 O/X 기호와 효과음만으로 진행해 다국어 시청층을 노린다.
- **실사 채널에 옮기면**: 집에서 실제로 실패한 요리 1개를 골라 ① 실패 장면 정면 고정 촬영(끊지 않기) ② 과거 NG 클립 1~2개를 앞에 붙여 5초 콜드오픈 ③ 탑다운으로 원인 X·해결 O 2~3개를 도마 위에서 재촬영 ④ 마지막에 45° 핸드헬드로 완성 조리 몽타주 + 정면 성공 미소. 편집은 CapCut 역재생·타자기 자막·차임/버저만으로 충분.
