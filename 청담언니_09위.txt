- **첫 프레임**: 0.0s 무자막 MCU. 화면 오른쪽에 여성 얼굴(시선은 볼, 입 살짝 벌림), 왼쪽 절반은 보라 장갑 두 손과 작은 얼음이 가득 찬 유리볼. 라벤더 회색 벽·꽃무늬 원피스. '얼굴+정체불명 얼음 물체'라 첫 프레임만으로 궁금증은 충분하지만, 실제 유튜브 썸네일(src.jpg)은 약 3.3초 프레임(O자 입+빨간 X 자막)이다.
- **0~1초**: 0.0~0.8s 얼음볼을 천천히 돌리며 관찰(정적 긴장) → 1.0s 볼이 휙 흔들리며 속 얼음이 움직임(모션블러, 온셋 1.16s)
- **0~3초**: 1.2s 윙크하듯 찡그림, 1.25~1.6s 고음 비명(-6.2dB, 영상 최대) → 1.4s 편집 줌아웃으로 와이드 전환+빨간 네온 자막 타자 시작 → 1.6~1.8s 자막 완성+X, 약 1.75s 저음 버저 → 2.0s 멍한 표정 → 2.2s 점프컷으로 다시 타이트 크롭(볼 기울임) → 2.6s 두 번째 빨간 자막 타자 시작 → 2.8s 자막+X(덜 녹음) → 3.25s 두 번째 비명, 약 3.6s 버저. 3초 안에 실패 판정 2회.
- **첫 자막/문구 의도**: 첫 자막이 결론(X)부터 나온다 — 1.4초에 '너무 얼렸다'는 실패 판정이 먼저 뜨고 정답은 숨겨 '그럼 뭐가 맞지?'라는 질문을 남긴다. 제목형 상단 고정 자막이나 설명 문장 없이 판정 자막만 쓴다.

- **중간 재훅·오픈 루프**: X→O 즉시 페어링(실패 다음 컷에 해결)으로 미니 클리프행어 반복 / 빨강/초록 2색 판정 자막 + 버저/차임 효과음의 일관된 규칙 / 실패 순간 비명·탄성(1.5s, 3.3s, 9.3s, 29.5s, 45.5s, 47.0s) / 장소·배경색 5회 전환(스튜디오→조리대→싱크대→창가→냉장고→스튜디오→창가) / '무엇을 만드는지' 결과물을 54초까지 숨김 / 성공 직후 한 번 더 X(컷 39)로 재후킹 / 마지막 5.9초 7컷 빠른 결과물 몽타주
- **엔딩·루프**: 컷 48(58.93~59.93s) 창가 산뷰 배경 완성 음료를 1초 회전으로 보여 준 뒤 CTA·엔딩카드 없이 끊는다. 재생이 0.0초 얼음볼 프레임으로 돌아가며 '얼음 결과물 → 얼음 재료'로 자연스럽게 이어지는 루프. BGM 저음(50Hz대)이 끝까지 이어져 끊김이 어색하지 않다.
- **훅 점수 이유**: 1.2초 실패+비명, 3초 안 X 2회, 1.75초 버저로 초반 후킹은 강력. 다만 0.0~1.0초는 무자막 관찰이라 완전 첫 1초는 조용하고, 예쁜 결과물을 초반에 한 번도 미리 보여 주지 않아 궁금증에만 의존 → 8점.

## 떡상 공식
0.0s 무자막 MCU: 얼굴+얼음 가득한 유리볼 — 무엇을 만드는지 설명 없이 사건 한가운데서 시작 → 1.2s 첫 실패 리액션+비명 → 편집 줌아웃 → 빨간 네온 X 자막 타자 등장 → 버저 → 2.2~4.4s 크롭 교차 점프컷으로 두 번째 X — 3초 안에 '실패 수집' 포맷 선언 → 장소 전환(조리대 하이앵글)으로 얼음끼리 안 붙는 근본 실패 + 비명(컷 6) → 싱크대 물줄기·거름망 고역 ASMR로 이완하며 첫 초록 O(물로 크기 맞추기, 컷 8~17) → 탑다운 조립 → X(기울면 미끄러짐) → 바로 다음 컷 O(가운데 작은 컵 누르기)+정답 차임(컷 18~23) → 창가 뷰로 이동해 상온에서 이글루가 무너지는 대형 실패+비명(컷 24~28), 0.8초 정적 → 분홍 레트로 냉장고 소품으로 냉동 5분 O+차임(컷 29~31) → 스튜디오 얼굴 파트: 바로 떼기 X, 문지르기 X → 물에 3초 담금 O → 4.15초 첫 성공 리빌+환호+차임(컷 32~38) → 성공 직후 투명도 X로 재후킹 → 살짝 담금 O → OK 사인+차임(컷 39~41) → 마지막 5.9초 결과물 조립 7컷 몽타주(음료 붓기·얼음컵 얹기·그라니타·키위) → 1초 회전 완성샷에서 CTA 없이 끊어 첫 프레임(얼음볼)으로 루프

## 왜 떡상했나
1. 0~3초에 실패 2연타: 1.2s 찡그림+1.3~1.6s 비명(-6.2dB, 영상 최대 음량) → 1.4s 빨간 X 자막 → 1.75s 버저, 2.8s 두 번째 X — 3초 안에 'NG 판정 게임' 규칙을 완성해 조회 4,074만(구독 935만의 약 4.4배)을 만든 첫 장치.
2. 판정 자막 13개(X 8개·O 5개)가 약 4.6초마다 하나씩 나오고, X 바로 다음 컷에 O를 붙이는 페어링(컷 19→21, 26·27→29, 32·34→35, 39→40)으로 '다음 판정'을 보려고 끝까지 보게 한다.
3. 소리로 판정을 찍는다: 실패 버저(79Hz 기본음·158/237Hz 배음) 약 9회, 정답 차임(740/932/1109/1480/1661Hz 화음) 4회(컷 22·30·38·41). 컷-온셋 일치율 12.8%로 우연 기준 36.6%보다 낮아 컷은 비트가 아니라 판정 자막·동작 타이밍에 맞춘 편집이다.
4. 무대사(Whisper 말소리 0초)인데도 비명·탄성이 영상 최대 음량(1.5s -6.2dB, 9.25s -6.1dB)이라 댓글이 비명 횟수 세기·목소리 반응으로 번지고, 통합 -9.9 LUFS의 큰 마스터가 타격감을 키운다.
5. 얼굴 46.9%(컷 1~5, 32~41 스튜디오 정면)는 판정 리액션, 얼굴 없는 손·물체 컷 53.1%(컷 6~31, 42~48)는 공정 담당으로 역할이 분리되고, 장소 5곳(스튜디오·조리대·싱크대·창가·분홍 냉장고)을 순환해 시각 피로를 막는다.
6. 마지막 5.9초(컷 42~48)에 7컷(0.37~2.03초)을 몰아 분홍 그라니타+키위 음료 위 얼음컵을 완성해 제목의 '이렇게 만드세요' 약속을 보상하고, 1초 회전 완성샷(컷 48)에서 CTA 없이 끊어 첫 프레임 얼음볼로 루프한다.

## ⚡ 컷 리듬(빡빡빡)

검출 48컷 중 9개는 오검출(11~17 거름망 흔들기 모션블러, 23 손 진입, 31 냉장고 문 닫힘 와이프) → 실컷 39개, 분당 39.0컷, 평균 1.54초, 중앙값 1.28초. 얼굴 파트(0~8s, 34~54s)는 1~4초 점프컷으로 느긋하게 리액션을 보여 주고, 공정 파트(8~34s)는 장소·앵글 전환으로 리듬을 만들며, 55~60s는 초당 1.2컷(컷 45~47은 0.37~0.43초)으로 빡빡빡 몰아친다. 검출 누락은 컷 7 안 점프 1회(약 12.2s) 추정 정도라 누락 포함 시 분당 약 40컷.

- **실제 컷** 39개 · 평균 1.54초 · 중앙값 1.28초 · 분당 39.0컷
- **가장 빠른 연타 구간**: 컷 44~48(56.97~59.93s): 5컷 2.96초 = 초당 1.69컷, 컷 45·46·47 길이 0.37·0.42·0.43초 — 결과물(그라니타·키위·완성샷) 조립 몽타주
- **가장 긴 컷**: 컷 37(4.15s, 첫 성공 리빌), 컷 32(3.93s, 서리 얼음볼 떼기 시도), 컷 6(3.92s, 얼음이 접시에 흩어지는 실패), 컷 18(3.18s, 집게 조립) — 모두 결과 확인이 필요한 컷에 길이를 배정
- **배속·슬로모**: 명확한 스피드 램프 없음. 컷 1의 약 1.2→1.4s 편집 줌아웃(스케일 램프), 컷 10~17 거름망 흔들기·18~19 집게 조립은 약 2배속 추정(13~17 구간 소리가 온셋 0개·hf 0.50의 뭉개진 노이즈라 배속 가능성) — 확정 불가.

## 🔊 소리·ASMR

무대사(Whisper 말소리 0초)인데 소리가 4층으로 설계됐다: ① 공백 없는 밝은 BGM(무음비 0.1%), ② 판정 효과음 — 실패 버저(79Hz 기본음, 158/237Hz 배음)가 X마다, 정답 차임(740/932/1109/1480/1661Hz 화음)이 큰 해결 4번(24.8s·33.0s·48.3s·52.8s), ③ 여성의 비명·탄성(1.5s -6.2dB, 9.25s -6.1dB = 영상 최대 음량), ④ 현장음 ASMR(샤워기 물줄기 hf 0.641, 거름망 흔들기 hf 약 0.50, 얼음볼 문지르기 hf 0.483, 집게 딸깍). 통합 -9.9 LUFS·True Peak +1.2dBFS·LRA 6.9로 매우 크게 마스터링. 평균 고역비 0.126, 초당 온셋 2.29.

- **ASMR(현장음)**: 싱크대·거름망·집게·얼음볼 문지르기 공정 구간(컷 7~21, 33)에서만 현장음을 BGM 위로 올림 — 고역비가 컷 7 0.641, 13~17 약 0.50, 33 0.483으로 스튜디오 구간(0.07~0.19)보다 3~8배.
- **배경음악**: 경쾌한 무가사 BGM 추정(추정 BPM 152), 저음 50~60Hz가 자주 깔리고 마지막 59~60s까지 지속. 중앙 레벨(약 -17dB 근처)로 판정음·비명 아래에 둠.
- **목소리**: 말은 없고 비언어 발성만 — 실패 때 고음 비명(약 0.9~1.2kHz, 1.5s·3.3s·9.3s·29.5s), 성공 때 환호성(45.5s·47.0s·51.5s). 비명이 영상 최대 음량.
- **효과음**: 실패 버저(저음 '뿌-' 계열, 약 9회)와 정답 차임('띠리링' 화음, 4회) 두 종류만 반복 사용 — 효과음 어휘를 2개로 제한해 규칙처럼 학습시킴.
- **BGM 추정**: 밝고 통통 튀는 무가사 팝/코믹 BGM 추정(추정 BPM 152) — 곡명 확인 불가 · 역할: 공백을 없애는 배경 에너지. 컷은 비트에 맞추지 않고, 판정음·비명이 그 위로 튀도록 중간 레벨 유지. 컷 28(-32dB)에서만 거의 빠져 정적을 만든 뒤 차임으로 복귀. · 크기: 전체 중앙값 -17.2dB 근처 — 비명(-6dB)·차임(-8.7dB)·버저(-12dB)보다 5~11dB 낮음
- **목소리 상세**: 있음 · 무대사 — 비명·탄성·웃음 등 비언어 발성만(Whisper 말소리 추정 0초) · 실패 순간(1.3~1.6s, 3.25s, 9.25s, 10.8s, 29.5s)과 성공 순간(45.5s, 47.0s, 51.5s)에 집중. 판정 효과음보다 0.2~0.5초 먼저 나와 '리액션→판정' 순서.
- **믹스**: 통합 -9.9 LUFS(쇼츠 일반 -14 기준보다 약 4LU 큼), True Peak +1.2dBFS(오버), LRA 6.9. 최대 피크는 비명(1.5s, 9.25s)과 차임(25.0s, 48.5s, 53.0s). BGM은 상시 깔리되 현장음 구간(컷 7~17)에서 물·얼음 고역이 위로 올라오고, 무너짐 직전 컷 28에서 전체를 -32dB로 떨어뜨려 대비를 만든다. 컷-온셋 일치율 12.8% vs 우연 36.6% → 소리에 맞춘 컷이 아니라 동작·자막 타이밍 편집.
- **소리 먼저 오는 순간**: 화면을 안 봐도 버저=실패, 차임=성공을 알 수 있게 설계 — 효과음 어휘를 2개로 제한하고 비명을 가장 크게 둬 소리만으로 이야기가 따라가진다.

### 다른 쇼츠와 확실히 다른 점
1. 판정 시스템: 빨강=X/초록=O 네온 자막 + 버저/차임을 13번 일관되게 반복 — 정답 레시피만 보여 주는 일반 요리 쇼츠와 달리 실패 8개 자체를 콘텐츠로 만든다.
