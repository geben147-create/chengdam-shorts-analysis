- **어그로 유형**: 개봉 순간(캔 뚜껑 팝) · 얼굴 리액션·윙크 · 재료→완성물 변신 궁금증 · 추억의 알사탕 캔(향수) · 제목의 비현실 사물(열기구) 약속 · 시즌 이벤트(어린이날 전날)

- **0~3초**: 1.23s 점프컷 → 1.4s 집게가 캔 속으로 → 1.6s 초록 사탕을 얼굴 높이로 → 1.8s 윙크 → 2.0s 사탕을 렌즈 코앞으로 내밀기 → 2.18s 탑다운 공정 컷으로 전환(2.2s 사탕 1알, 2.4s 2알, 2.6s 4알, 2.8s 5알 — 0.12~0.15초 스톱모션 미세컷).
- **첫 자막/문구 의도**: 없음 — 화면 텍스트·자막·스티커 0개(OCR 70컷 모두 빈칸). 훅은 100% 행동(개봉)·소리(캔 팝)·표정(놀람·윙크)으로만 만든다.
- **약속 → 회수**: 제목이 약속한 열기구는 35.6s(#51)에 얼굴과 함께 첫 공개, 음료 합체는 47.7s(#64 히어로샷, 썸네일 구도)에서 완성. 약속 이행까지의 36초를 사탕 그릇(10.7s)·빨간 구(21.0s)·과자 반전(25.1s) 세 번의 중간 보상으로 채운다.
- **중간 재훅·오픈 루프**: 약 10~12초 간격 변신 공개 4회(#15·#32·#51·#64) / 스톱모션 미세 점프컷(#3 약 15회, #45 2회, #62 약 7회) / 스튜디오 얼굴 리액션 복귀 6블록 / 소품을 렌즈로 내밀어 넘기는 전환 5회(#2·#17·#18·#43·#57) / 공개 직전 음량 정적(#49~#50, -27~-30dB) → 공개 +18dB / 재료 반전(#36 국민 과자 봉지 등장) / 3개 세트 교대(스튜디오/창가 카페/대리석 조리대)로 배경 변화
- **엔딩·루프**: 마지막 #70(57.53~58.28s) 엄지척·윙크는 첫 컷과 같은 스튜디오·같은 의상·같은 정면 구도라 반복 재생 시 이음새가 약한 부분 루프다. 루프를 노린 동작 연결(예: 캔을 다시 드는 동작)은 없다.
- **훅 점수 이유**: 0.4초 안에 개봉 행동+얼굴 표정이 시작되고 1초 내 사탕 공개까지 가는 빠른 훅이지만, 제목의 핵심 결과물(열기구)은 첫 3초에 나오지 않아 훅 자체는 7점. 결과물은 썸네일이 대신 약속하고, 본편은 중간 보상 4회로 유지율을 버는 구조.

### 소재
- **소재**: 알사탕 캔(여러 색 캔디 볼) → 녹여 만든 스테인드글라스 사탕 그릇(바구니) + 빨간 사탕을 녹여 반구 몰드로 만든 사탕 구(풍선) + 동그란 슈 과자 + 나무 꼬치 = 먹는 열기구 토퍼. 아래는 딸기·적포도·얼음·탄산을 담은 긴 잔 에이드.
- **새로움·비틀기**: 음료 위에 '먹을 수 있는 열기구'를 얹는 3종 합체(사탕 공예+국민 과자+과일 에이드). 흔한 사탕 그릇 만들기를 비음식 사물(열기구) 형태로 재조립해 댓글에서 '만화 속 풍선 같다'는 반응을 얻었다.
- **시즌·트렌드 연결**: 어린이날 전날 업로드(5/4), 추억의 알사탕·야구 캐릭터 국민 과자, 사탕 녹여 그릇 만들기(캔디 볼) 트렌드, 봄 딸기 시즌.
- **채널 반복 요소**: 채널의 '에이드·음료 빌드'(drink 섹터) 반복 포맷 — 과일+얼음+탄산 긴 잔 위에 사탕·과자 토퍼를 얹는 구조(같은 섹터 영상이 채널 상위권에 다수 있는 것으로 추정).

## 떡상 공식
0.0~1.2s 스튜디오 정면 얼굴 + 알사탕 캔 뚜껑 따기(개봉 소리 + 놀란 표정)로 시작 → 1.2~2.2s 재료 한 알을 윙크와 함께 렌즈로 내밀어 공정 컷으로 넘김(렌즈 밀착 전환) → 2.2~4.7s 탑다운 스톱모션으로 사탕 모자이크 채우기 — 톡톡 소리 연타(빡빡빡 1) → 4.7~10.7s 타임랩스로 녹이고 창가 세트에서 머들러로 그릇 모양 잡기(0.1~0.6초 컷 연타) → 10.7~13.3s 얼굴 옆 첫 공개: 유산지 떼는 최대 바스락 ASMR(보상 1) → 13.3~21.0s 두 번째 재료(빨간 사탕판) 소개 → 녹이기 점프 체인 → 몰드 붓기(음악 위주 구간) → 21.0~25.1s 몰드에서 빨간 반구 뽑기 + 윙크(보상 2), 손 전용 세트에서 반구 2개 정리 → 25.1~32.6s 국민 과자 봉지 반전(바스락) → 반구에 과자 채우고 닫아 사탕 구 완성 → 32.6~35.6s 창가 세트에서 꼬치 스톱모션 조립 → 가위 컷 → 음량을 죽인 정적 → 35.6~39.7s 과자 열기구 얼굴 공개(음량 +18dB, 보상 3) → 과자 추가 → 렌즈로 내밀기 → 39.7~49.1s 딸기·포도 손질 → 잔 빌드(스톱모션→실시간 붓기) → 합체 → 썸네일 구도 히어로샷(보상 4) → 49.1~58.3s 스튜디오 먹방 리액션(바삭·호로록) → 엄지척 윙크로 첫 컷과 같은 구도 마무리

## 왜 떡상했나
1. 58초에 실제 컷 67개(검출 70개 중 오검출 3개 제외, 분당 69컷, 중앙값 0.65초)에 더해 같은 구도 안의 미세 점프컷이 약 35회 숨어 있어 실제 편집점은 약 102개(초당 약 1.75회)다. 특히 #3(2.18~4.70s)은 사탕 한 알 놓기를 0.12~0.15초 간격 약 15회로, #62는 딸기 쌓기를 약 7회로 스톱모션 압축해 반복 공정이 전혀 지루하지 않다.
2. 변신 공개를 약 10~12초 간격으로 4번 배치했다: #15(10.7s) 사탕 그릇 → #32(21.0s) 빨간 사탕 구 → #51(35.6s) 과자 열기구 → #64(47.7s) 음료 합체 히어로샷. 제목이 약속한 열기구는 35.6초에야 나오지만 그 전까지 중간 보상이 끊기지 않는다.
3. 화면 글자 0개(OCR 70컷 전부 빈칸)·말소리 0초(Whisper 세그먼트 없음)의 완전 무언어 포맷이다. 인기 댓글 60개 중 약 28%(17개)가 영어·스페인어이고 번역투 한국어 댓글까지 합치면 약 40%가 해외 시청자로 보여, 조회수 2,207만(하루 약 15만)의 글로벌 확산 구조를 만든다.
4. 얼굴 출연 비중은 길이 가중 39.7%(23컷)이며, 공정은 손/물체(60.3%)로 보여 주고 공개·맛보기는 반드시 스튜디오 얼굴로 돌아온다(#1·#15·#32·#36·#51·#65, 6블록). 댓글 약 20%가 미소·외모 칭찬으로 '사람=브랜드' 효과가 확인된다.
5. 소리를 구간별로 바꿔 귀가 쉬지 않는다: 유산지·과자봉지 바스락 컷은 ASMR을 앞에(#15 고역비 0.681, #16 0.615, #36 0.513), 시럽 녹이기·붓기(#20~#31)는 고역비 0.001~0.03의 음악 위주다. 열기구 공개 직전 #49~#50을 -27~-30dB로 낮췄다가 #51 공개에서 -12.4dB로 약 18dB 끌어올린다.
6. 어린이날 전날(2026-05-04) 업로드 + 풍선·알사탕·국민 과자라는 어린이 코드 조합으로 댓글의 약 12%가 어린이날·어릴 적 추억·조카 이야기다. 시즌 이벤트와 소재를 정확히 맞춘 기획이다.

### 편집 순서
1. 1) 타임라인 60fps 세로 프로젝트, 첫 컷은 캔 개봉 1.2초 → 같은 구도 점프컷으로 사탕 윙크, 사탕이 렌즈를 덮는 프레임에서 컷
2. 2) 탑다운 사탕 놓기 원본에서 한 알 놓인 직후 8~9프레임씩만 잘라 15조각 연속 배치(총 2.5초), 각 조각 시작에 톡 소리가 오도록 오디오도 같이 자르기
3. 3) 녹이기는 인터벌 클립 1.5초 + 창가 성형 컷들을 0.1~0.6초로 잘라 연타, 같은 동작은 다른 앵글 1컷만 추가
4. 4) 공개 컷(얼굴 옆 떼기·반구 뽑기·열기구)은 0.7~1.9초로 길게 남기고, 공개 컷의 현장음(바스락)을 +6dB 올리고 음악은 -6dB 덕킹
5. 5) 녹이기·붓기 구간은 반대로 현장음을 줄이고 BGM을 앞으로 — 0.3~0.65초 점프컷 6개 체인
6. 6) 소품을 렌즈로 내미는 컷은 초점이 무너지는 프레임에서 컷해 다음 세트로 하드컷 전환
7. 7) 메인 공개 직전 2컷의 전체 볼륨을 -12dB 내려 정적을 만든 뒤, 공개 컷에서 원래 볼륨 + 바스락으로 복귀
8. 8) 잔 빌드는 딸기 붙이기 스톱모션(7조각) → 얼음·탄산 붓기 실시간 2.5초로 스피드 램프
9. 9) 히어로샷 1.4초 정지 → 먹방 리액션(씹기·빨대 소리 강조) → 첫 컷과 같은 정면 구도 엄지척으로 종료
10. 10) 마스터: 통합 -12~-11 LUFS, 트루피크 -1 dBFS 리미터, 자막·텍스트 없이 내보내기

## 🐹 적용하기
- **그대로 가져갈 것**: 무자막·무내레이션 + 현장음 ASMR 구조(해외 확산용) / 약 10초 간격 중간 공개 4회 설계(그릇→구→과자→합체) / 반복 공정은 스톱모션 미세 점프컷으로 압축(한 동작=한 컷=한 소리) / 공정은 손, 공개·맛보기는 얼굴로 돌아오는 교대 / 소품을 렌즈로 내밀어 덮는 전환 / 공개 직전 음량을 죽이는 정적
- **바꿀 것**: 첫 3초 안에 완성된 열기구를 0.5초 플래시로 먼저 보여 주는 결과 선공개 훅 추가(현재 35.6초까지 결과물 없음) / 트루피크 +1.6 dBFS는 과함 — -1 dBFS 리미터로 클리핑 방지 / 따라 하기 실패 댓글 대응으로 재료·온도 정보를 설명란이나 고정 댓글에 제공 / 마지막 컷을 첫 컷(캔 들기) 동작과 이어지게 만들어 완전 루프화
- **AI 동물 캐릭터 쇼츠에 옮기면**: AI 캐릭터(예: 작은 동물 셰프)가 알록달록 사탕을 녹여 '먹는 열기구'를 만들어 음료 위에 띄우는 무대사 쇼츠. 공정 컷은 탑다운·45° 손 클로즈업 스톱모션으로, 공개 컷은 캐릭터 얼굴 옆에서 소품을 렌즈로 내미는 구도로 만들고, 각 컷에 바스락·톡톡·호로록 현장음을 개별 생성해 믹스한다. 약 10초마다 변신 공개 1회, 공개 직전 음악을 빼는 정적 연출을 그대로 가져간다.
- **실사 채널에 옮기면**: 편의점 사탕+과자로 만드는 '음료 위 토퍼' 시리즈: 스튜디오 정면(얼굴·소품 렌즈 푸시), 창가 테이블(조립·히어로샷), 조리대(녹이기·붓기) 3세트를 한 공간 안에서라도 배경을 바꿔 촬영. 반복 공정은 폰 고정 탑다운 스톱모션, 소품 옆 핀마이크로 바스락·톡톡을 따로 녹음해 크게 믹스한다.
